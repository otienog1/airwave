Three engagement features — where do we start?

These are independent enough that each deserves its own spec and plan. Pick one to design first, then we'll come back for the others.

A

Trending Stations

Surface which stations are hot right now — listener spikes, fastest growing, most plays today. Backend already returns growth data; this is mostly a UI addition to the main page.

Effort: small · Impact: discovery + FOMO

B

Now Playing Cards + Share

Expand the song-detection display into a proper "Now Playing" card with artist, track, and a share button that generates a link or image. nowPlaying data is already in PlayerContext.

Effort: medium · Impact: social spread + virality

C

Listening History

Show users what stations they've listened to, for how long, and when. Backend endpoint already exists. Turns passive listening into a personal story users want to return to.

Effort: small · Impact: retention + re-engagement
