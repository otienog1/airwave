## Task 2: Filter inactive stations from grid

**Files:**
- Modify: `hooks/useStationFilter.ts`

Stations with `is_active === false` should never appear in the grid regardless of search/filter state.

- [ ] **Step 1: Read `hooks/useStationFilter.ts`**

Find where `filteredStations` is computed (the `useMemo`).

- [ ] **Step 2: Add active-only filter as the first step**

In the `filteredStations` memo, before any other filter:
```ts
const filteredStations = useMemo(() => {
  let result = stations.filter(s => s.is_active !== false); // exclude explicitly inactive
  if (searchTerm)
    result = result.filter(s =>
      s.name.toLowerCase().includes(searchTerm.toLowerCase()) ||
      s.description?.toLowerCase().includes(searchTerm.toLowerCase())
    );
  if (selectedGenre !== 'All') result = result.filter(s => s.genre === selectedGenre);
  if (selectedRegion !== 'All') result = result.filter(s => s.region === selectedRegion);
  return result;
}, [stations, searchTerm, selectedGenre, selectedRegion]);
```
